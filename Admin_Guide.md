# Admin Guide
## How to Update Your Portfolio (No Coding Needed)

This guide explains how to log in and update every part of your website once it's built. You will never need to touch code to make changes — everything below is done through the Admin Dashboard in your browser.

---

## 1. Logging In

1. Go to `yourwebsite.com/admin`
2. Enter your admin email and password (set up during development).
3. You'll land on the **Dashboard** — a sidebar menu lists every section you can edit.

> 🔒 Keep your admin password private. If you forget it, use the "Forgot Password" link, or ask your developer to reset it from Supabase.

---

## 2. Updating Your Basic Info (Hero / About)

- Go to **Profile / Hero** in the sidebar.
- Edit your **Name, Title, Tagline, Bio**, and upload a new **Profile Photo** anytime.
- Click **Save**. Changes appear on the live site within seconds.

---

## 3. Updating Education

- Go to **Education**.
- Click **+ Add Entry** to add a new degree/program, or click an existing card to **Edit**.
- Fields: Degree name, Institution, Logo (upload image), Start/End Date, Description.
- Drag entries up/down to reorder them (most recent usually goes first).
- Click **Delete** (trash icon) to remove an outdated entry.

---

## 4. Updating Skills

- Go to **Skills**.
- Add a new **Category** (e.g., "Lab Skills") or edit existing ones.
- Inside a category, click **+ Add Skill**, name it, pick an icon, and set a proficiency level (0–100%) using the slider.
- Reorder by dragging.

---

## 5. Adding Projects

- Go to **Projects**.
- Click **+ Add Project**.
- Fill in: Title, Description, Cover Image (upload), Tags (e.g., "Research", "Hackathon"), and any links (GitHub repo, live demo, published paper).
- Save — it instantly appears in your Projects grid on the live site.

---

## 6. Adding Certifications

- Go to **Certifications**.
- Click **+ Add Certificate**.
- Fill in: Title, Issuing Body, Date, upload the certificate file (image or PDF), and an optional verification link.
- This is where things like your IIT JAM scorecard or JGEEBILS certificate live.

---

## 7. Adding Achievements

- Go to **Achievements**.
- Click **+ Add Achievement**.
- Fill in: Title, Level (Regional/National/etc.), Result (e.g., "1st Rank"), Description, Date, and an optional photo.

---

## 8. Managing the Gallery

- Go to **Gallery**.
- Click **+ Upload Images** — you can select multiple photos at once.
- Add a short caption to each if you like.
- Drag to reorder, click the trash icon to remove any photo.

---

## 9. Updating Your Resume

- Go to **Resume**.
- Click **Upload New Resume** and select your latest PDF.
- The "Download Resume" button on your live site will automatically point to this new file — no other changes needed.
- You can see how many times it's been downloaded on this page.

---

## 10. Reading Contact Messages

- Go to **Messages**.
- Every message someone submits through your Contact form appears here, newest first.
- Click a message to mark it as read.
- (Optional, if set up) You'll also get an email notification when a new message arrives.

---

## 11. Switching Light/Dark Mode Default

- Go to **Theme**.
- Choose whether the site should default to Light, Dark, or "Match Visitor's System Setting" (recommended).
- Visitors can still manually switch using the toggle in the navbar regardless of your default.

---

## 12. General Tips

- **Always double-check on mobile** after making a big change — open the live site on your phone to make sure it looks right.
- **Image sizes:** for best performance, avoid uploading extremely large image files (over 5MB) — resize/compress photos before uploading if possible.
- **Don't panic:** nothing you do in the Admin Dashboard can "break the code" — it only changes content, not the site's structure.
- If something looks visually broken (not just a content issue), that's a development issue, not an admin issue — contact your developer.

---

## 13. Who to Contact for Help

If you run into an issue that isn't about editing content — e.g., the site won't load, login isn't working, or you want a new *type* of section added — that requires a code change and should go to whoever built the site (developer/Antigravity project owner), not something fixable from this dashboard.
